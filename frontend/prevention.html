Interactive Checklist

🔗 Detect Malicious URLs & Emails

Before clicking any link or acting on an email, run through this checklist. Click each item to mark it as checked.

URL Safety Checklist 0/8 completed
Check the domain spelling carefully Look for subtle misspellings: amaz0n.com, sbi-bank.co.in, paypa1.com, uidai-india.xyz
Verify it uses HTTPS (padlock icon) HTTP sites are not encrypted. However, HTTPS alone doesn't guarantee legitimacy — scammers also use HTTPS.
Watch for suspicious TLDs Official Indian government sites use .gov.in. Be wary of .xyz, .tk, .ml, .cf, .ga domains in official-looking messages.
Expand shortened URLs before clicking Use unshorten.it or hover over the link to see the destination. Scammers hide malicious URLs behind bit.ly, tinyurl, etc.
Verify the sender's email domain Check if the domain after @ matches the official company domain. "support@sbi-bank-helpdesk.com" is NOT sbi.co.in
Look for urgent/threatening language "Act within 24 hours", "Your account will be suspended", "Legal action will be taken" — these are pressure tactics.
Check for unexpected requests Did you initiate this transaction or verification? Unsolicited requests for OTPs, PINs, or document uploads are red flags.
Scan the link with VirusTotal Copy the URL and check it at virustotal.com for malware before opening anything suspicious.
Step-by-Step Guide

🔐 Setting Up Two-Factor Authentication (2FA/MFA)

2FA adds a second layer of security so even if your password is stolen, attackers cannot access your account. It's one of the most effective protections available.

1

Open Google Account Settings

Go to myaccount.google.com and click on "Security" in the left sidebar.

2

Find "2-Step Verification"

Under "How you sign in to Google", click on "2-Step Verification" and then "Get started".

3

Choose Your Second Factor

Recommended: Google Authenticator app. Avoid SMS-based 2FA if possible (SIM swap vulnerability). Select "Authenticator app" for best security.

4

Scan the QR Code

Download Google Authenticator from the Play Store, open it, tap the + button, and scan the QR code shown on screen.

5

Save Backup Codes

Google provides 10 backup codes. Print or store these securely offline. They allow access if you lose your phone.

ℹ️ Note: Indian banks are mandated by RBI to use 2FA for all online transactions. The standard method is OTP via SMS. However, you should additionally secure your banking app/net banking login itself.
1

Enable app PIN / Biometric Lock

In your bank's mobile app settings, enable fingerprint/face unlock AND a separate app PIN. This prevents access even if your phone is unlocked.

2

Set Transaction Alerts

Enable SMS and email alerts for ALL transactions, even ₹1. This gives you immediate notice of unauthorized transactions.

3

Set Transaction Limits

In net banking, set daily UPI/NEFT/RTGS limits to the minimum you need. Reduce limits when traveling abroad.

4

Use a Dedicated Email for Banking

Create a separate email address used only for banking communications. Never use this email for social media or shopping.

5

Register a Secondary Phone for OTPs

Some banks allow registering a second number for OTPs. Use a phone not associated with social media accounts to reduce SIM swap risk.

📘 Facebook / Instagram

  1. Settings & Privacy → Security and Login
  2. Two-Factor Authentication → Edit
  3. Choose Authentication App
  4. Scan QR with Google/Microsoft Authenticator
  5. Enter the 6-digit code to confirm

🐦 Twitter / X

  1. More → Settings → Security and account access
  2. Security → Two-factor authentication
  3. Select Authentication App
  4. Follow prompts to link your authenticator
  5. Download and store backup codes

💼 WhatsApp

  1. Settings → Account → Two-step verification
  2. Enable → Create a 6-digit PIN
  3. Add a recovery email address
  4. This prevents SIM swap account takeover
  5. Never share this PIN with anyone

Authenticator apps generate time-based 6-digit codes that change every 30 seconds. They are much safer than SMS-based OTPs.

Security Essential

🗝️ Setting Up a Password Manager

A password manager generates and stores unique, strong passwords for every account. You only need to remember one master password.

Why use one?

  • ✓ Generates unique 20+ character passwords for every site
  • ✓ Prevents password reuse (biggest vulnerability)
  • ✓ Alerts you when a site you use has been breached
  • ✓ Auto-fills on correct domains (won't fill on phishing sites)
  • ✓ Encrypted vault with zero-knowledge architecture

Recommended Options

  • Bitwarden FREE — Open source, most trusted, cross-platform
  • 1Password — Premium, excellent family plan, travel mode
  • Dashlane — Includes VPN and dark web monitoring
  • Browser Built-in — Convenient but avoid for banking passwords
1

Download Bitwarden (Free)

Install the Bitwarden browser extension from the official Chrome/Firefox extension store and the mobile app from Play Store.

2

Create a Strong Master Password

Use a memorable passphrase of 4-5 random words: "Mango-River-Shield-89-Kite". Do NOT use your name, birthdate, or any personal info. Never write this down digitally.

3

Import / Save Existing Passwords

Bitwarden can import from Chrome, Firefox, or other managers. Enable the browser extension to auto-capture passwords as you log in.

4

Audit and Strengthen Weak Passwords

Use Bitwarden's Security Report to find weak, reused, or breached passwords. Change all flagged passwords starting with banking and email.

5

Enable 2FA on Your Password Manager

This is critical — your password manager is the master key. Protect it with an authenticator app as the second factor.

Security Hygiene

📱 Mobile & Browser Security Best Practices

📱 Mobile Device Security

Keep OS and apps updated Enable auto-updates. Most attacks exploit known vulnerabilities in outdated software.
Only install apps from official stores Never install APK files from WhatsApp, email, or third-party websites.
Review app permissions regularly Settings → Apps → Review which apps have access to Camera, Contacts, SMS, Location.
Enable device lock with strong PIN/biometrics Use a 6-digit PIN minimum or fingerprint. Avoid pattern locks.
Disable "Install from Unknown Sources" Settings → Security → ensure "Install Unknown Apps" is off for all apps.
Beware public Wi-Fi Never access banking or sensitive accounts on public Wi-Fi. Use mobile data or a VPN.

🌐 Browser Security

Install uBlock Origin ad blocker Blocks malicious ads, trackers, and many phishing redirects automatically.
Enable Safe Browsing (Google Chrome) Settings → Privacy and security → Security → Enhanced protection.
Never save passwords in the browser for banking Use a password manager extension instead. Browser-saved passwords are vulnerable to extensions.
Check for HTTPS before entering data Look for the padlock icon. Click it to verify the certificate belongs to the correct domain.
Bookmark important banking/government sites Access them only through bookmarks — never from search results or links in messages.
Regularly clear browser cookies and cache Reduces tracking and exposure to session hijacking. Monthly clearing is good practice.
